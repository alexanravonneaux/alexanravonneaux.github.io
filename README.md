# Portfolio d’Alexan RAVONNEAUX

Site portfolio personnel d’Alexan RAVONNEAUX, étudiant en BUT Science des Données à l’IUT de Niort. Il présente son parcours, ses projets et ses coordonnées.

## Présentation

Ce site statique est réalisé en HTML, CSS et JavaScript. Il sert de portfolio personnel et de vitrine professionnelle.

## Structure du projet

- `index.html` — page d’accueil
- `portfolio.html` — présentation, compétences et coordonnées
- `projets.html` — présentation des projets
- `apropos.html` — parcours et informations personnelles
- `style.css` — styles partagés
- `img/` — images et autres ressources visuelles
- `docs/` — documents complémentaires, comme le CV

## Voir le site

Le site est déployé à l’adresse suivante : [alexanravonneaux.github.io](https://alexanravonneaux.github.io)

## Prévisualiser le site en local

Ouvrez `index.html` dans un navigateur, ou lancez un serveur local depuis la racine du dépôt :

```bash
python -m http.server 8000
```

Puis rendez-vous sur <http://localhost:8000>.

## Déploiement

Le dépôt est configuré pour être publié avec GitHub Pages. Vous pouvez vérifier la configuration dans **Settings → Pages** du dépôt.

## Personnalisation

Modifiez les pages HTML pour mettre à jour le contenu et les liens, remplacez les ressources dans `img/` et adaptez les styles partagés dans `style.css`.
